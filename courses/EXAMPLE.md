# Course data — schema and example

This file is the template. Copy it to `courses/<short-name>.md`, one file per
course, and fill it in from your syllabus. Everything in `courses/` except this
file is gitignored, so your instructors' names, your enrollment codes, and your
deadlines stay on your machine.

The skills in `.claude/skills/` deliberately contain **no** course specifics.
They supply method; these files supply facts. A skill that needs a due date, a
grade weight, or a rubric reads it here and says so if it is missing.

Delete sections that do not apply to a given course. Keep the headings you do
use verbatim — the skills look for them by name.

## Platforms

Where work is submitted and where authoritative updates appear. Name the system
of record explicitly — when it disagrees with the syllabus PDF, it wins.

- **System of record** — CourseWorks / Canvas / Gradescope
- **Communication** — course Slack `#general`, `#tech-support`
- **Required materials** — textbook, enrollment code, hardware kit

## Routing

Which skill handles this course, and which parts go to the other one.

- **Primary skill** — `writing` or `technical`
- **Crossover** — e.g. blog posts about a hardware build are a `writing` job
  about a `technical` artifact

## Deliverables

One entry per assignment type. Quote the syllabus; do not paraphrase it. Record
length in the units the syllabus uses, and record the win condition — a
completion-graded journal and a polished essay need different advice.

### Assignment Type A (30%)

- **Spec** — approx. 600–800 words on a topic of the student's choice
- **Due** — Friday 11/6, to the TA, before midnight
- **Format** — double spaced, 12-point Times New Roman, MLA or Chicago
- **Graded on** — letter grade
- **Win condition** — argument quality; polish counts

### Assignment Type B (20%)

- **Spec** — groups of two to three, 10-minute oral presentation
- **Due** — rotating, claimed in section
- **Graded on** — rubric below

## Policies

- **Late work** — half a letter grade per day; nothing accepted past 7 days
- **Attendance** — one absence free; each additional costs 10% of participation
- **Materials** — hardware returned at end of term or 20% deducted
